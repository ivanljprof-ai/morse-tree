# 🌲 Morse Binary Tree — Interactive Morse Decoder & Translator

Un decodificador e intérprete interactivo de Código Morse basado en una estructura de **Árbol Binario**, diseñado con una estética visual moderna de cristal (Glassmorphism), efectos brillantes ambientales y temática de circuito impreso.

## ✨ Características Principales

- 🌳 **Árbol Binario Interactivo**: Visualización gráfica completa de la jerarquía del código Morse.
  - **Izquierda (Largo / Hold)**: Avanza por el camino de la **Raya (`—`)**.
  - **Derecha (Corto / Tap)**: Avanza por el camino del **Punto (`·`)**.
- 🔊 **Sintetizador de Audio Morse**: Generación de tonos de audio en tiempo real al ingresar señales.
- ⚡ **Navegación Dinámica**: Resaltado interactivo de nodos y caminos según las pulsaciones del usuario.
- ⌨️ **Múltiples Métodos de Entrada**:
  - **Teclado**: Presiona espacios o teclas dedicadas para emitir puntos y rayas.
  - **Ratón / Pantalla Táctil**: Haz clic o mantén pulsado en la interfaz.
- 🔄 **Traductor Bidireccional**: Decodifica señales Morse a texto plano y convierte texto a Morse al instante.
- 🎨 **Diseño Estilo Apple**: Interfaz ultramoderna con *glassmorphism*, iluminación ambiente y diseño adaptativo (*responsive*).

## 🚀 Uso e Instalación

No requiere compilación ni dependencias complejas. Es un proyecto de frontend puro.

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/ivanljprof-ai/morse-tree.git
   cd morse-tree
   ```

2. **Abrir en el navegador:**
   - Haz doble clic en `index.html` o abre el archivo en tu navegador preferido (Chrome, Safari, Firefox, Edge).
